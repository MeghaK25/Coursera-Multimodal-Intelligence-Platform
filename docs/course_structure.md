## Notes

- Module `04` is explicitly labeled `optional` in its folder name.
- The `03_final-assignment` folder contains 1 peer-review assignment delivered as two HTML files.  
  One HTML embeds a large base64-encoded PNG infographic (~500 KB).
- The `05_digital-badge` folder contains an IBM badge HTML page (~157 KB) which is an administrative asset, not a learning asset.
- Every video lesson has **exactly two** transcript representations: `.en.srt` (timed subtitles) and `.en.txt` (plain text). There are no orphan transcripts or orphan videos — every MP4 has both.
